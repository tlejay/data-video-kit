ใส่ลง .env แล้วเช็คแบบไม่เสียเครดิต

Easiest: run /kiki-init in Claude Code. Or by hand in the terminal, from the kit folder:

data-video-kit, terminal
# 1) create .env (skip if it exists)
$ cp -n .env.example .env
# 2) API key: typed hidden, never shown on screen or saved in shell history
$ read -rs K && python3 scripts/set-env.py ELEVENLABS_API_KEY "$K"; unset K
ELEVENLABS_API_KEY=(hidden) -> ~/data-video-kit/.env
# 3) voice ID (not secret)
$ python3 scripts/set-env.py ELEVENLABS_VOICE_ID abcd1234EXAMPLEvoice
ELEVENLABS_VOICE_ID=abcd1234EXAMPLEvoice -> ~/data-video-kit/.env
# 4) free check: credits left per key
$ python3 scripts/tts-quota.py
  key1   free     left    9,650 /   10,000  reset 05 Nov (in 23d)

  total 9,650 chars left  =  ~12 clips at 750 chars
  best single key 9,650 chars  <- a clip cannot span two keys
# 5) cost of the example script, nothing is sent
$ python3 scripts/tts-clip.py --dir examples/korat-solar/script --dry-run
[tts] dry run: 7 clip(s), 620 chars, about 52 s, ~0.19 USD (check one key has room: scripts/tts-quota.py --need 620)
