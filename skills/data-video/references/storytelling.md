# Storytelling and hook techniques (reference)

A distilled "content hook and storytelling techniques" sheet. SKILL.md step 4 holds the
default shape; read this when a video needs a different shape (persuasion, case study,
personal story) or the default hook feels flat. These are tools, not a formula that
guarantees views.

Goal chain: **Stop → Interest → Retention → Remember → Action.**

## Hooks (0 to 3 s)
- **BLUF**: verdict first, explain after. "AI ไม่ได้ทำให้คนตกงาน คนที่ใช้ AI เป็นอาจได้เปรียบกว่า"
- **Pattern interrupt**: break the expectation. "หยุดใช้ AI แบบนี้ ถ้าไม่อยากเสียเงินเปล่า"
- **Curiosity gap**: a gap between what they know and want to know. "มีเหตุผลหนึ่งที่บริษัทใหญ่ไม่ค่อยพูดถึง"
- **Contrarian**: against the common view. "ประชุมน้อยลงไม่ได้ทำให้งานเร็วขึ้นเสมอไป"
- **Question**: the viewer's own problem. "ทำไมบริษัทมี AI แล้วพนักงานยังเหนื่อยเท่าเดิม?"
- **Data**: a striking number.
- **In medias res**: start mid-event. "ตอนนั้นระบบล่ม และลูกค้ากำลังสมัครพร้อมกันหลายร้อยคน"

## Keeping them watching
Open loop (ask now, answer later), progressive disclosure (one piece at a time), story gap,
micro-cliffhanger between sections, pacing (vary fast and slow), **payoff** (deliver what
the opening promised). Hook starts the view, retention keeps it, payoff makes it worth it.

## Story frameworks
| Framework | Shape | Use for |
|---|---|---|
| Inverted pyramid | most important → details | news, explainers (our default) |
| Pyramid principle | conclusion → reasons → evidence | executive / data briefings |
| SCQA | situation → complication → question → answer | business presentations |
| PAS | problem → agitate → solution | marketing, sales |
| AIDA | attention → interest → desire → action | ads |
| Before-after-bridge | before → after → how | case studies |
| Rule of three | three points | any explanation |
| Hero's journey | start → obstacle → change → result | brand / personal stories |

## Pick by goal
- Make them stop: pattern interrupt + hook
- Say it fast: BLUF + inverted pyramid (data videos)
- Watch to the end: curiosity gap + open loop + payoff
- Easy to understand: rule of three + progressive disclosure
- Persuade: PAS + AIDA
- For executives: BLUF + pyramid principle + SCQA
- Tell an experience: in medias res + hero's journey

## Worked 60 s example (AI in business)
- 0-3 BLUF+hook "บริษัทคุณอาจไม่จำเป็นต้องจ้างคนเพิ่ม แค่ต้องหยุดทำงานแบบเดิม"
- 3-15 problem + curiosity gap "ซื้อ AI มาแล้วพนักงานกลับเหนื่อยกว่าเดิม เพราะอะไร?"
- 15-45 rule of three "ไม่มี process, ข้อมูลกระจัดกระจาย, ไม่มีคนรับผิดชอบ"
- 45-55 payoff "ก่อนซื้อ AI ให้ออกแบบกระบวนการก่อน"
- 55-60 CTA "ลองดูว่างานไหนในบริษัทต้องทำซ้ำทุกวัน"

The core: build an expectation worth having, then actually deliver on it.
