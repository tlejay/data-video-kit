# risograph (cover sample only)

Screen-print editorial: 3 spot inks (yellow, orange-red, blue) on cream paper, halftone,
misregistration, cut paper, stamps. Made as one option in a template-choice round; not built
into a full video yet. `python3 build.py --shot` writes `sample.html` and `preview.jpg`
(the cover on top, the sticker strip below). `t4.js` needs `lib.js`.
